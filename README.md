# Datheon_Python_Programming_Intenship
Python Programming Intenship Projects-Datheon


## Project 1: Hangman Game

A simple word-guessing game developed using Python. Players guess letters to find the hidden word within a limited number of attempts.

## Project 2: Stock Portfolio Performance Tracker

A Python-based application that calculates stock investment, market value, profit or loss, and percentage gain or loss. It also saves the portfolio summary to a CSV file.

## Technologies Used
- Python 3
- CSV Module
- File Handling

## Files Included
- hangman.py – Hangman word-guessing game
- portfolio.py – Stock portfolio tracker
- portfolio_summary.csv – Portfolio report
